# Checklist diario de camiones y semi trailers · Grupo Paredes

Versión web estática lista para GitHub Pages o Netlify. Conserva el diseño actual, fecha automática, acceso por DNI, nombre automático, evaluación de la unidad, firma del conductor e impresión en PDF.

El logo está incorporado en la página para que también se muestre aunque el alojamiento no encuentre la carpeta `assets`.

## Publicación

Sube el contenido de esta carpeta a la raíz del repositorio o alojamiento. Si usas GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**. Si publicas en Netlify, asegúrate de que `index.html` quede en la raíz.

El filtro de DNI es básico y se valida en el navegador. GitHub Pages y Netlify publican la página en internet.
